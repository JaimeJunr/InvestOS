Catálogo de Plugins

Prioridade: P0 — sem uma lista curada, o setup interativo (Gerador de Workspace) não tem o que oferecer.

User Stories

US-001 — Como operador do InvestOS, quero uma lista central de plugins/skills/MCPs de investimento organizada por domínio, para escolher no setup sem pesquisar do zero toda vez.

  • Blocked by: (none)
  • AC: catálogo cobre os 4 domínios (research, risco/portfólio, dados de mercado, corretora/banco).
  • AC: cada entrada tem nome, repo/link, tipo (plugin/skill/agent/MCP), credencial exigida (sim/não).

US-002 — Como operador, quero que cada entrada declare se exige credencial/API key de terceiro, para decidir com informação se vale habilitar aquele domínio agora.

  • Blocked by: US-001
  • AC: entradas sem credencial (ex.: baseadas em yfinance público) ficam marcadas separadamente das que exigem (Plaid, Interactive Brokers, Alpha Vantage tier pago, CPZAI).

US-003 — Como operador, quero que o catálogo deixe explícito que hoje não existe MCP/skill curado equivalente para dados de mercado brasileiro (B3/fundos/ANBIMA), para não assumir cobertura que não existe.

  • Blocked by: US-001
  • AC: domínio "dados de mercado" registra o gap BR de forma visível (não omitido, não maquiado como "em breve").

Functional Requirements

  1. Catálogo é um documento/config versionado (ex.: catalog.json) listando, por domínio, entradas com: nome, repo, tipo, credencial exigida (sim/não), disclaimer herdado (se o README de origem citar "não é recomendação de investimento").
  2. Critério de entrada: repositório público, com marketplace.json válido (plugins) OU instalação documentada (skills/MCPs) — sem exigência de teste prévio de qualidade; é catálogo de research, não certificação.
  3. Setup interativo (Gerador de Workspace) lê este catálogo para oferecer as opções por domínio escolhido.
  4. Gap de dados de mercado BR é registrado explicitamente no catálogo, não omitido.
  5. Atualização do catálogo é manual (curadoria humana), não scraping automático.

Scope

In: lista curada e documentada por domínio, critério de entrada, registro explícito do gap BR.

Out: instalação automática dos plugins escolhidos (isso é do Gerador de Workspace consumindo o catálogo); validação de qualidade real de cada plugin além do README; busca automática de novos plugins.

Dependencies

Consumida por Gerador de Workspace (US-002 lá). Sem dependências próprias.
